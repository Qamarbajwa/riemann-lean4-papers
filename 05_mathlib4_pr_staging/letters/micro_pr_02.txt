This small pull request adds two short helper lemmas, Int.fract_natCast_div_eq_mod_div and Int.fract_palindromic_add_eq, to Mathlib/Algebra/Order/Floor.lean.

In the existing floor library, Int.fract_neg has a non-zero split whenever the fractional part is nonzero, so reflecting rational steps (L - 1 - m) / k and m / k for a common multiple L = k * q forces repeated case splits by hand. Adding these two lemmas closes that small gap in one clean pass.

Here is the step-by-step calculation:

Step 1: For any natural numbers n and k >= 1, divide n by k with quotient q1 = n / k and remainder r1 = n % k < k, so n / k = q1 + r1 / k in R.
Step 2: Since 0 <= r1 / k < 1 and q1 is an integer, subtracting q1 leaves Int.fract (n / k) = (n % k : R) / k.
Step 3: When k divides L and m < L, set r = m % k. By Euclidean division on the reflected point L - 1 - m, its remainder modulo k is k - 1 - r.
Step 4: Adding both fractional parts gives
  ((k - 1 - r) + r) / k = (k - 1) / k = 1 - 1 / k.
