In the earlier pushes, we defined the partial harmonic cell L2 sum harmonicCellL2PartialSum c N M = sum_{n=1}^M (A_c(n))^2 / (n * (n + 1)) and showed that over any finite set S of primes between N + 1 and M it is bounded below by sum_{p in S} 1 / (2 * p^2). Two very natural questions remained open: first, how do we bound the remaining tail from M + 1 to M' without depending on the huge period L_N = lcm(1, ..., N), and second, how do we connect the finite algebraic sum harmonicCellL2PartialSum directly to the MeasureTheory Lebesgue set integral on Ioc 0 1?

This single push closes both gaps in Lean 4. First, using the simple fact that every fractional part Int.fract (n / k) lies between 0 and 1, the triangle inequality gives the uniform bound |A_c(n)| <= 1 + sum_{k=1}^N |c_k| for all n, which depends only on c and N and never on L_N. Second, by telescoping the cell widths 1 / (n * (n + 1)) = 1 / n - 1 / (n + 1) as in Euclid's Book X method of exhaustion, we prove that the tail energy between M and M' is at most B^2 / (M + 1). Third, because the continuous residual equals the constant A_c(n) on each half open harmonic cell Ioc (1 / (n + 1)) (1 / n) when D1 = 0, we integrate cell by cell to prove that harmonicCellL2PartialSum c N M equals the Lebesgue set integral over Ioc (1 / (M + 1)) 1 and therefore bounds the full Lebesgue integral over Ioc 0 1 from below.

The step by step maths behind how this works is very simple:

Step 1: On the null slope hyperplane D1 c N = 0, the discrete cell residual equals the modular cell residual:
A_c(n) = 1 - sum_{k=1}^N c_k * Int.fract (n / k).
Since 0 <= Int.fract (n / k) < 1 for every n and k, taking absolute values gives the period free uniform bound
|A_c(n)| <= 1 + sum_{k=1}^N |c_k| * |Int.fract (n / k)| <= 1 + sum_{k=1}^N |c_k| = B.

Step 2: Now look at the tail L2 sum from cell M + 1 to cell M' (with 1 <= M <= M'):
T(M, M') = sum_{n = M + 1}^{M'} (A_c(n))^2 / (n * (n + 1)).
Since |A_c(n)| <= B, we have (A_c(n))^2 <= B^2, so factoring out B^2 gives
T(M, M') <= B^2 * sum_{n = M + 1}^{M'} 1 / (n * (n + 1)).

Step 3: Use the partial fraction identity 1 / (n * (n + 1)) = 1 / n - 1 / (n + 1) to telescope the sum of widths from M + 1 to M':
sum_{n = M + 1}^{M'} (1 / n - 1 / (n + 1)) = 1 / (M + 1) - 1 / (M' + 1) <= 1 / (M + 1).
Putting this into Step 2 gives T(M, M') <= B^2 / (M + 1), which is smaller than any epsilon > 0 whenever M + 1 > B^2 / epsilon.

Step 4: Next, to connect the finite sum to the Lebesgue integral on a single cell I_n = Ioc (1 / (n + 1)) (1 / n), remember that for every x in I_n we have n <= 1 / x < n + 1, so continuousNymanResidual c N x = A_c(n). Integrating the constant (A_c(n))^2 over I_n gives the constant times the interval length:
integral_{x in I_n} (continuousNymanResidual c N x)^2 = (A_c(n))^2 * (1 / n - 1 / (n + 1)) = (A_c(n))^2 / (n * (n + 1)).

Step 5: The union of the disjoint half open cells I_1, I_2, ..., I_M is the interval Ioc (1 / (M + 1)) 1. By induction on M using MeasureTheory.setIntegral_union, summing the single cell integrals from n = 1 to M gives
integral_{x in Ioc (1 / (M + 1)) 1} (continuousNymanResidual c N x)^2 = harmonicCellL2PartialSum c N M.

Step 6: Since Ioc (1 / (M + 1)) 1 is a subset of Ioc 0 1 and the squared integrand is non negative and integrable on Ioc 0 1, monotonicity of the Lebesgue set integral gives
harmonicCellL2PartialSum c N M <= integral_{x in Ioc 0 1} (continuousNymanResidual c N x)^2.

Step 7: Combining Step 6 with the multi prime lower bound from the previous file immediately gives
sum_{p in S} 1 / (2 * p^2) <= integral_{x in Ioc 0 1} (continuousNymanResidual c N x)^2
for every finite set S of primes greater than N.
